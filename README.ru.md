*Краткая версия – полное описание в [английском README](README.md).*

Больше играбельных рас для **Conquest of Azeroth** (CoA), модуль AzerothCore.

Игровой клиент Conquest of Azeroth уже содержит модели, скины и причёски многих рас, которые не может выбрать ни один игрок: гоблины, воргены, пандарены, вульперы, врайкулы и другие. Этот модуль делает их играбельными. Каждая новая раса опирается на стандартную расу – место старта, характеристики, расовые способности и фракция, – но сохраняет свой облик. Клиентский патч собирается из собственного клиента игрока; моделей модуль не содержит. **Тестовая версия.**

## Установка

Проще всего с [AFK Realm](https://github.com/aspollon/AFK-Realm): «Модули → Управление модулями» добавляет модуль, пересобирает сервер и приносит всё нужное; страница настройки модуля на русском. Без AFK Realm: см. английский README.

Тексты, которые AFK Realm показывает для этого модуля, переведены в `lang/`.
