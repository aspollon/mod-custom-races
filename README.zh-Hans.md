*简短版——完整说明见[英文 README](README.md)。*

为 **Conquest of Azeroth**（CoA）提供更多可玩种族的 AzerothCore 模块。

Conquest of Azeroth 的游戏客户端本身就带有许多玩家无法选择的种族的模型、皮肤和发型：地精、狼人、熊猫人、狐人、维库人等等。本模块让它们可以游玩。每个新种族都依托一个原版种族——出生地、属性、种族技能和阵营——但保留自己的外观。客户端补丁由玩家自己的游戏客户端生成；本模块不附带任何模型。**测试版。**

## 安装

最简单的方式是使用 [AFK Realm](https://github.com/aspollon/AFK-Realm)：在“模块 → 管理模块”中添加本模块，它会重新编译服务器并带上所需的一切；本模块的设置页面提供简体中文。不使用 AFK Realm：请参阅英文 README。

AFK Realm 显示的本模块文本已翻译在 `lang/` 中。
