Más razas jugables para **Conquest of Azeroth** (CoA), un módulo de AzerothCore.

El cliente del juego de Conquest of Azeroth ya trae los modelos, pieles y peinados de muchas razas que ningún jugador puede elegir: goblins, huargen, pandaren, vulpera, vrykul y más. Este módulo las hace jugables. Cada raza nueva se apoya en una raza básica – lugar de inicio, atributos, habilidades raciales y facción – pero conserva su propio aspecto. El parche de cliente se crea a partir del cliente del propio jugador; el módulo no trae modelos. **Versión de prueba.**

## Instalación

Lo más sencillo es con [AFK Realm](https://github.com/aspollon/AFK-Realm): *Módulos → Gestionar módulos* añade el módulo, vuelve a compilar el servidor y trae todo lo necesario; la página de configuración del módulo está en español. Sin AFK Realm: consulta el README en inglés.

Los textos que AFK Realm muestra de este módulo están traducidos en `lang/`.
