Plus de races jouables pour **Conquest of Azeroth** (CoA), un module AzerothCore.

Le client de jeu de Conquest of Azeroth contient déjà les modèles, peaux et coiffures de nombreuses races qu’aucun joueur ne peut choisir : gobelins, worgens, pandarens, vulpérins, vrykuls et d’autres. Ce module les rend jouables. Chaque nouvelle race s’appuie sur une race de base – lieu de départ, caractéristiques, capacités raciales et faction – tout en gardant sa propre apparence. Le patch client est construit à partir du client du joueur ; le module n’apporte aucun modèle. **Version de test.**

## Installation

Le plus simple avec [AFK Realm](https://github.com/aspollon/AFK-Realm) : *Modules → Gérer les modules* ajoute le module, recompile le serveur et apporte tout le nécessaire ; la page de configuration du module est en français. Sans AFK Realm : voir le README anglais.

Les textes qu’AFK Realm affiche de ce module sont traduits dans `lang/`.
