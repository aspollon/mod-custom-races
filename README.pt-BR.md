Mais raças jogáveis para o **Conquest of Azeroth** (CoA), um módulo do AzerothCore.

O cliente do jogo do Conquest of Azeroth já traz os modelos, peles e cabelos de muitas raças que nenhum jogador pode escolher: goblins, worgens, pandarens, vulperas, vrykuls e mais. Este módulo as torna jogáveis. Cada raça nova se apoia numa raça padrão – local de início, atributos, habilidades raciais e facção – mas mantém a própria aparência. O patch de cliente é gerado a partir do cliente do próprio jogador; o módulo não traz modelos. **Versão de teste.**

## Instalação

O mais fácil é com o [AFK Realm](https://github.com/aspollon/AFK-Realm): *Módulos → Gerenciar módulos* adiciona o módulo, recompila o servidor e traz tudo o que é preciso; a página de configuração do módulo está em português. Sem o AFK Realm: veja o README em inglês.

Os textos que o AFK Realm mostra deste módulo estão traduzidos em `lang/`.
